**Versão atual:** 20261020c  
**Loja:** https://convencao-site.rickjax123.workers.dev/

## Site de Vendas

Loja de refrigerantes online com produtos frescos e horário de entrega.

## Características

- Compra online fácil
- Variedade de refrigerantes, água e chopp
- Entrega rápida
- Horário de funcionamento
- App Android para cliente e vendedor

## Categorias

- Destaque (2L, 600ml, 350ml)
- Refrigerantes 2L
- Refrigerantes 600ml
- Refrigerantes 350ml
- Refrescos e Chinotto
- MSX Energético
- Água
- Chopp Ravache

## Como usar

1. Acesse https://convencao-site.rickjax123.workers.dev/
2. Navegue pelas categorias
3. Adicione ao carrinho e finalize a compra
4. Para instalar o app, abra **Configurações → Baixar aplicativo (APK)**

## Painel do vendedor

- Painel: https://convencao-site.rickjax123.workers.dev/admin.html
- APK do painel: `apk/convencao-vendedor.apk`
- Login com **Manter conectado** por 1, 7 ou 30 dias
- Pedidos de todos os aparelhos, status, preços, ferramentas e bot do Telegram

## Tecnologias

- HTML5 + CSS3
- JavaScript puro
- Firebase (preços e pedidos via gateway)
- Cloudflare Workers (gateway e site)
- Android (APK cliente e vendedor)
