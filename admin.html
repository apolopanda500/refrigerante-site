Preços em tempo real

Opcional. Com a URL do banco, os preços que você salvar aparecem na hora na página de todos os clientes. Crie em console.firebase.google.com → Realtime Database → modo teste e cole a URL aqui.

Como criar o banco (1 minuto)

  1. Abra console.firebase.google.com e entre no projeto planning-with-ai-9b2c9.
  2. No menu da esquerda clique em Realtime Database (ou Banco de dados em tempo real).
  3. Clique em Criar banco de dados → escolha a região United States → Avançar.
  4. Escolha Começar no modo de teste e conclua.
  5. Pronto! Não precisa colar nada aqui: o site encontra o banco sozinho.

Depois de criar, volte aqui e clique em Testar. Se aparecer “Tudo certo”, é só editar os preços e clicar em Salvar e aplicar: todos os clientes veem na hora.

Sincronização com a nuvem

Bot do Telegram - comandos do vendedor

Além do aviso de novo pedido, o bot aceita comandos. Toque no botão / do Telegram para ver todos: /confirmar, /separacao, /enviado, /entregue, /cancelar, /ultimos, /status, /hoje e /ajuda. Na mensagem de cada pedido também tem botões para mudar o status com um toque.

Os comandos são aplicados no navegador onde o painel está aberto (deixe esta página aberta para funcionar na hora). O status do cliente continua sendo alterado por aqui também.
